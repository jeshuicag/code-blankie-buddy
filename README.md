Project Description:
Social media is a free and effective way to advertise products, but illiteracy, security concerns, weak connections, and digital illiteracy can prevent small operators in offline areas from taking advantage of these opportunities. Now, You See Me takes one social media account— instagram in this case– and gives everyone who uses the Now, You See Me application an easy, visually guided way to upload videos and images of their products with a heartfelt message and english caption to that account. Besides the actual upload to instagram, video and image edits through the app can all be run and stored locally, so videos are ready when connectivity is back. Voice filtering and optional location/ phone number inclusions also ensure anonymity at the level the user desires. As the account grows from a collective effort, so does visibility for everyone.
